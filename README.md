# uikit-steps

Cucumber step definitions for the components of any site built on UIkit 3 (dialogs, side panels, drop-downs and
drops, accordions, switchers and tabs, the navigation bar with its toggle on a narrow screen, alerts, notifications,
tooltips, slideshows and sliders, the lightbox, sticky elements and the states of a form), with
[webship-js](https://webship.co/docs/webship-js/2.0.x), a BDD browser automation harness built on Playwright and
Cucumber-js.

The steps, their features, the demo site and CI come with the first release, `2.0.0`.
